# Agent workflow

Shared rules and skills: the user-level install of `simonliu99/agent-workflow` (its README). This file holds only this project's block.

## This project

- **Project:** `simonliu99/dota-replays`: a Python CLI (`dota_replays.py`, `opendota_client.py`, `database.py`) that tracks players' matches through the OpenDota API, stores them in SQLite and downloads replays to a TrueNAS share, with `publish.py` (the match index), `db_copy.py` (the dated database backups), `replay_folder.py` (the replay folder check), the switchboard job entries in `jobs/` and `scripts/switchboard-submit`. Sibling: `simonliu99/switchboard`, whose dota-replays module runs these jobs and shows the match list (switchboard #29).
- **Engineering rules:** none beyond the shared rules. Python 3.10 or later, standard library only (user decision 2026-10-28, switchboard #29); no OpenDota API key. Tests never write to the working directory or call OpenDota.
- **Records:** state file `/Users/simonliu/Code/scratch/dota-replays/state.md`. Queue: this repository's issues. The design record is switchboard #29's approved plan, named in the state file.
- **PR check:** `gh pr view <n> -R simonliu99/dota-replays --json headRefOid --jq .headRefOid`. **Sequence:** `scripts/sequence --run <new dir>`, the one copy of the steps: `python -m unittest discover -v --durations 3` from the repository root under a 570 s bound, on a clean checkout, under Python 3.12 or newer (3.13 preferred: the script takes `python3.13` from `PATH`, else `python3` at 3.12 or newer, else it exits 2 and names what it found). Its `summary.txt` opens with `revision <sha> tree <sha>`, then the python, load, `step unittest` (exit code, wall and CPU time, case counts) and slowest-case lines, and ends `result PASS` or `result FAIL <reason>`; it exits 0 only on `result PASS`, and reports its step to the hub through `scripts/lib/run_queue_progress.py`, agent-workflow's version 1 copied byte for byte. **Runs:** the sequence and the gate are switchboard commit jobs on any worker whose policy lists the task (macbook-pro and neptune), with `--resource none --backstop 900 --quiet 300` and no `--os`. The worker's run, after its last commit is pushed: `run-queue submit --task sequence --project dota-replays --purpose sequence-<n> --class focused --cwd <worktree> --head <head> --resource none --backstop 900 --quiet 300 --notify "$PASEO_AGENT_ID"`. The integrator's gate, on the merge tree: `run-queue submit --task gate --project dota-replays --purpose gate-<n> --class gate --cwd ~/Code/dota-replays --base origin/master --merge <head> --resource none --backstop 900 --quiet 300 --notify coordinator:dota-replays`, whose summary's `tree` must equal `git merge-tree --write-tree origin/master <head>`. `run-queue artifacts <id> <new dir>` writes the run directory as `<new dir>/out/sequence/` or `<new dir>/out/gate/`. A single test file on an uncommitted tree runs as a `local` job: `run-queue submit --project dota-replays --purpose '<purpose>' --class focused --cwd <worktree> --resource none --backstop 300 --quiet 120 -- python3.13 -m unittest tests.<module> -v`. **Merge steps:** AGENTS.md §6 (the coordinator's scripts are not versioned yet).
- **Integration branch:** `master`.
- **Coordinator ops:** `<scratch root>/ops/<coordinator id>/`. **Scratch root:** `/Users/simonliu/Code/scratch/dota-replays`. **Paseo project:** `dota-replays`, on the Mac daemon.
- **Hosts:** the Mac runs development and every agent; macbook-pro and neptune run the sequence and gate jobs; the Maryland node runs the data jobs as a switchboard worker, which reads the database from the worker's local folder (`SWITCHBOARD_BULK`, switchboard #29 level 1); TrueNAS holds the replays. Agents never run commands on the Maryland node or TrueNAS.
- **Risk tiers:** high: credentials or tokens, and anything that deletes or overwrites replays or the database; medium: other code changes; low: docs and records.
- **Issue domains:** none; titles are `type: description`.
- **Cross-repository:** switchboard owns the module contract (manifest, document store, job environment); this repository adopts it after the switchboard side merges.
- **Aggregate facts at integration:** none.
